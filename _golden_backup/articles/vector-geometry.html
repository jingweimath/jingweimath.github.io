# 向量代数与空间解析几何

考研数学数一对向量代数与空间解析几何这部分是有明确要求的；数二和数三的考试大纲里并没有直接写出要求，但是考题中经常有这方面的影子。本部分虽然主要针对数一的复习，其他同学了解一些结论有助于提高分数！

---

一、向量代数常用结论

1) 数积（点乘、内积） —— 结果是数量：

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta \quad (\text{也是夹角公式})$$
  • 向量的模：$|\mathbf{a}| = \sqrt{\mathbf{a} \cdot \mathbf{a}}$
  • $\mathbf{a} \cdot \mathbf{b} = 0$ 表示两个向量垂直
  • 向量在轴上的投影：$\text{Prj}_\mathbf{a}\mathbf{b} = |\mathbf{b}|\cos\varphi$；所以 $\mathbf{a} \cdot \mathbf{b}$ 也可以看成是 $|\mathbf{a}|$ 与 $\mathbf{b}$ 在 $\mathbf{a}$ 上的投影之积

2) 向量积（叉乘、矢积） —— 结果是向量，方向符合右手法则：

$$|\mathbf{a} \times \mathbf{b}| = |\mathbf{a}||\mathbf{b}|\sin\theta$$
  • $\mathbf{a} \times \mathbf{b} = \mathbf{0}$ 表示两个向量平行
  • $\mathbf{a} \times \mathbf{b} = -\mathbf{b} \times \mathbf{a}$
  • 以 $\mathbf{a}, \mathbf{b}$ 为邻边的平行四边形面积 $= |\mathbf{a} \times \mathbf{b}|$

3) 混合积 —— 结果是数值：

$$[\mathbf{a}\,\mathbf{b}\,\mathbf{c}] = (\mathbf{a} \times \mathbf{b}) \cdot \mathbf{c}$$

由 $\mathbf{a}, \mathbf{b}, \mathbf{c}$ 形成的平行六面体体积 $= |[\mathbf{a}\,\mathbf{b}\,\mathbf{c}]|$。

---

二、平面及其方程

几何空间中三个变量 $x, y, z$ 的线性关系表示的是空间中的一个平面。

平面的一般方程：

$$Ax + By + Cz + D = 0$$
  • $D = 0$ 表示平面过原点
  • 缺一项（如 $Ax + By = D$）表示平面平行于 $z$ 轴
  • 缺两项（如 $Cz = D$）表示平面垂直于 $z$ 轴，即平行于 $xOy$ 坐标面

平面的确定方式：

1. 过不在一条直线上的三个点唯一确定一个平面 2. 过一点且与某一方向垂直唯一确定一个平面——点法式：

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

$\{A, B, C\}$ 称为平面的法向量

3. 过一条直线以及直线外的一个点唯一确定一个平面（若此直线过原点，则平面也过原点） 4. 空间中两条交叉直线唯一确定一个平面；两条平行直线也唯一确定一个平面

两个平面的夹角 等于其法向量的夹角：

$$\cos\theta = \frac{|A_1 A_2 + B_1 B_2 + C_1 C_2|}{\sqrt{A_1^2 + B_1^2 + C_1^2} \cdot \sqrt{A_2^2 + B_2^2 + C_2^2}}$$

点到平面的距离公式：

$$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

三、空间直线及其方程

空间直线的一般方程由两个平面方程联立表示：

$$\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}$$

对称式（点向式）：

$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

其中 $\{m, n, p\}$ 为直线的方向向量。

参数式：

$$\begin{cases} x = x_0 + mt \\ y = y_0 + nt \\ z = z_0 + pt \end{cases}$$
  • 直线之间的夹角就是方向向量之间的夹角
  • 直线与平面的夹角用方向向量与法向量的正弦计算
  • 直线与平面垂直：方向向量与法向量平行，$\dfrac{A}{m} = \dfrac{B}{n} = \dfrac{C}{p}$
  • 直线与平面平行：方向向量与法向量垂直，$Am + Bn + Cp = 0$

---

四、方向余弦

向量 $(m, n, p)$ 的方向余弦为：

$$(\cos\alpha, \cos\beta, \cos\gamma) = \left(\frac{m}{\sqrt{m^2+n^2+p^2}}, \;\frac{n}{\sqrt{m^2+n^2+p^2}}, \;\frac{p}{\sqrt{m^2+n^2+p^2}}\right)$$

这是一个单位向量。

---

五、线性方程组与平面的几何意义（常考点、重点）

代数中的三元一次线性方程组在空间几何上表示的是三个平面之间的关系：

$$\begin{cases} a_{11}x + a_{12}y + a_{13}z = b_1 \\ a_{21}x + a_{22}y + a_{23}z = b_2 \\ a_{31}x + a_{32}y + a_{33}z = b_3 \end{cases}$$

记 $\mathbf{a}_1 = (a_{11}, a_{21}, a_{31})^T$，$\mathbf{a}_2 = (a_{12}, a_{22}, a_{32})^T$，$\mathbf{a}_3 = (a_{13}, a_{23}, a_{33})^T$，$\mathbf{b} = (b_1, b_2, b_3)^T$，$A = (\mathbf{a}_1, \mathbf{a}_2, \mathbf{a}_3)$，则上式可写成：

$$x\mathbf{a}_1 + y\mathbf{a}_2 + z\mathbf{a}_3 = \mathbf{b} \quad \text{（向量组的线性表示）}$$
$$A\mathbf{X} = \mathbf{b} \quad \text{（矩阵方程）}$$

几何意义与解的关系：

1. 三个平面平行：方程组无解，且 $r(A) = 1$，$r(A, \mathbf{b}) = 2$；若三个平面重合，则 $r(A) = r(A, \mathbf{b}) = 1$，方程组有无穷多组解 2. 三个平面相交于一条直线：$r(A) = r(A, \mathbf{b}) = 2$，有无穷多组解 3. 三个平面两两相交（无公共交点）：$r(A) = 2$，$r(A, \mathbf{b}) = 3$，方程组无解 4. 三个平面相交于一个点：唯一解，$r(A) = r(A, \mathbf{b}) = 3$

可以推广到 $n$ 个方程（$n$ 个平面）的问题中。

六、曲面与二次曲面

三个变量 $x, y, z$ 的函数关系表示的是三维几何空间中的一个曲面：$F(x, y, z) = 0$。考研数学主要考察几个常见的二次曲面以及在坐标面上的投影（用于重积分计算）。

(i) 旋转曲面

已知 $yOz$ 面上的一条曲线 $f(y, z) = 0$：

  • 绕 $z$ 轴旋转生成的曲面为 $f\!\left(\pm\sqrt{x^2 + y^2},\; z\right) = 0$，即把 $y$ 换成 $\pm\sqrt{x^2 + y^2}$
  • 绕 $y$ 轴旋转生成的曲面为 $f\!\left(y,\; \pm\sqrt{x^2 + z^2}\right) = 0$，即把 $z$ 换成 $\pm\sqrt{x^2 + z^2}$

例1：旋转抛物面 $z = x^2 + y^2$，可以看成 $z = y^2$ 绕 $z$ 轴旋转而成。在 $xOy$ 面上的投影为圆心在原点的圆（半径取决于 $z$ 方向截面的值）；在 $yOz$ 面以及 $xOz$ 面上的投影都是抛物线。

例2：旋转圆锥面 $z^2 = x^2 + y^2$，可以看成 $z = y$ 绕 $z$ 轴旋转而成。在 $xOy$ 面上的投影为圆心在原点的圆；在 $yOz$ 面以及 $xOz$ 面上的投影都是直线。

例3：球面 $x^2 + y^2 + z^2 = R^2$，可以看成圆弧 $z = \sqrt{R^2 - y^2}$ 绕 $z$ 轴旋转而成。在三个坐标平面上的投影都是圆。

(ii) 柱面

柱面由母线沿准线移动生成。一般情形下，母线平行于某坐标轴，准线则在其垂直的坐标面上。

通常，柱面方程只含两个变量。比如 $F(x, y) = 0$ 表示母线平行于 $z$ 轴，准线为 $xOy$ 面上的曲线：

$$\begin{cases} F(x, y) = 0 \\ z = 0 \end{cases}$$

即方程中缺少哪个变量，柱面母线就平行于那根坐标轴。

例：圆柱面 $x^2 + y^2 = R^2$，母线平行于 $z$ 轴。在 $xOy$ 面投影是个圆；如果是圆柱体的话，在 $yOz$ 以及 $xOz$ 面上的投影都是矩形。

(iii) 其他二次曲面

椭球面以及双曲抛物面等极少考到，感兴趣的同学自行复习。

---

七、空间曲线

一般方程（由两个曲面的交线定义）：

$$\begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$$

参数方程：

$$\begin{cases} x = x(t) \\ y = y(t) \\ z = z(t) \end{cases}, \quad t \in I$$

在坐标面上的投影（以 $xOy$ 面为例）：

$$\begin{cases} H(x, y) = 0 \\ z = 0 \end{cases}$$

考研数学涉及到空间曲线的题目一般比较难，多用在曲线积分部分。
