📚 题库题目添加手册

一、文件结构说明

题库文件位于 questions/ 目录下：

  • ch1.json ~ ch13.json：按章节分类的题目
  • comprehensive.json：跨章节综合题
  • index.json：题目索引文件（控制哪些题目被加载）
⚠️ 重要：每次修改题目后，必须运行 python build_questions.py 重新生成 questions-bundle.js

二、题目格式规范

标准JSON格式

{
  "subject": "高等数学",
  "chapter": "第一章 函数、极限、连续",
  "chapterId": "ch1",
  "questions": [
    {
      "type": "choice",
      "question": "题目内容，支持LaTeX公式如 $\int_{0}^{1} x^2 dx$",
      "options": ["A. 选项A内容", "B. 选项B内容", "C. 选项C内容", "D. 选项D内容"],
      "answer": "A",
      "solution": "详细解析过程..."
    }
  ]
}

字段说明

字段 必填 说明
type ✅ choice（选择题）或 fill（填空题）
question ✅ 题目内容，支持LaTeX公式
options ⚠️ 选择题必填，填空题不需要
answer ✅ 答案（选择题填"A"/"B"/"C"/"D"，填空题填具体数值或表达式）
solution ✅ 详细解析过程

三、LaTeX公式使用指南

✅ 推荐使用的格式（显示效果好）

积分：

  • 简单上下限：$\int_{0}^{1}$ → ∫₀¹
  • 简单上下限：$\int_{a}^{b}$ → ∫ₐᵇ

分数：

  • $\frac{1}{2}$ → ½
  • $\frac{dy}{dx}$ → dy/dx

上下标：

  • $x^2$ → x²
  • $x_1$ → x₁

希腊字母：

  • $\alpha$ → α
  • $\beta$ → β
  • $\pi$ → π

⚠️ 已知显示问题的格式

复杂积分上下限会显示为原始LaTeX代码：
  • $\int_{-\infty}^{+\infty}$ → 用户会看到原始代码
  • $\int_{\pi/2}^{\pi}$ → 用户会看到原始代码

临时解决方案：对于复杂上下限，暂时用文字描述或等待后续升级渲染引擎

四、常见错误及避免方法

错误1：options缺少"A. "前缀

❌ 错误写法： 
"options": ["选项A内容", "选项B内容", ...]
✅ 正确写法： 
"options": ["A. 选项A内容", "B. 选项B内容", ...]

错误2：answer字段包含前缀

❌ 错误写法： 
"answer": "A. 正确选项"
✅ 正确写法： 
"answer": "A"

错误3：JSON格式错误

常见原因：

  • 缺少逗号
  • 多余逗号（最后一个元素后不能有逗号）
  • 引号不匹配
  • 中文引号（"，"）代替英文引号（"）

检查方法：

python -m json.tool your_file.json

错误4：忘记重新生成bundle

症状：修改了JSON文件，但网站上没有更新

解决方案：

cd C:\Users\yuwei\WorkBuddy\2026-06-03-task-2
python build_questions.py

五、添加题目的标准流程

步骤1：准备题目内容

在 questions/ 目录下找到对应的章节文件（如 ch1.json）

步骤2：按格式添加题目

参考"二、题目格式规范"，确保：

  • 所有必填字段都有
  • LaTeX公式使用推荐的简单格式
  • options有"A. "前缀
  • answer不包含前缀

步骤3：验证JSON格式

python -m json.tool questions/ch1.json

如果输出格式化后的JSON，说明格式正确。

步骤4：重新生成bundle

python build_questions.py

步骤5：本地测试

用浏览器打开 practice.html，检查：

  • 新题目是否出现
  • 公式显示是否正常
  • 选项显示是否完整
  • 答案和解析是否正确

步骤6：部署到服务器

# 使用SCP上传更新后的文件
scp practice.html root@62.234.131.123:/var/www/html/
scp questions-bundle.js root@62.234.131.123:/var/www/html/

六、快速检查清单

添加题目后，逐项检查：

  • JSON格式正确（用 python -m json.tool 验证）
  • 所有必填字段都有值
  • 选择题options有"A. "前缀
  • answer字段只包含答案，不包含前缀
  • LaTeX公式使用简单格式（避免复杂上下限）
  • 已运行 python build_questions.py
  • 本地测试通过
  • 已部署到服务器

七、紧急情况处理

网站打不开了

  1. 检查 questions-bundle.js 是否生成成功
  2. 检查 index.json 是否包含所有章节
  3. 回滚到上一个可用版本

题目显示乱码

  1. 检查JSON文件编码是否为UTF-8
  2. 检查是否有特殊字符未转义
